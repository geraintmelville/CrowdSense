# YAMNet SavedModel

This is the TensorFlow SavedModel for [YAMNet 1](https://tfhub.dev/google/yamnet/1), vendored so feature extraction can load the model from disk without contacting TensorFlow Hub at runtime.

The model and its class map are distributed by Google under the Apache License 2.0. See the [YAMNet source repository](https://github.com/tensorflow/models/tree/master/research/audioset/yamnet) for the license and model documentation.
